# Electron Dialog Assignment

A desktop application built with Electron, React, TypeScript, and Tailwind CSS

## Features
- Information Dialog
- Confirmation Dialog
- Settings Dialog
- Reusable Dialog Components
- Responsive Layout
- Tailwind CSS Styling

## Tech Stack
- Electron
- React
- TypeScript
- Tailwind CSS
- Vite

## Installation
Clone the repository from github

```bash
git clone <your-github-url>
cd electron-react-app
```

Install dependencies

```bash
npm install
```

Run the application

```bash
npm run dev
```

## Build
For macOS
```bash
npm run build:mac
```
For Linux

```bash
npm run build:linux
```

For Windows

```bash
npm run build:win
```
